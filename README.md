# ESP32-S3-MINI-Custom-Development-Board
Custom 4-layer ESP32-S3-MINI development board designed in Altium Designer with USB-C, USB-to-UART, and boot/reset circuitry.

I did this project to develop practical experience with embedded hardware design, multilayer PCB layout, component selection, schematic capture, design verification, and PCB fabrication outputs.
Features
- ESP32-S3-MINI microcontroller module
- 4-layer PCB design
- USB-C interface
- USB-to-UART programming and debugging
- Power regulation circuitry
- Boot and reset circuitry
- GPIO breakout headers
- Decoupling capacitors placed around major IC power pins
- Ground and power planes
- Custom schematic symbols and PCB footprints
- Designed and verified in Altium Designer

The project was prepared for PCB fabrication and assembly by generating:

- Gerber files
- NC drill files
- Bill of Materials (BOM)
- Pick-and-place data
- PCB fabrication layers
- Assembly information

These files are available in the Gerber directory.
